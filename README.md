**TypeScript na prática** — tipagem forte, generics, utilitários de tipo e configuração.

## 📋 Sobre

Estudos de TypeScript: do básico de tipos a patterns avançados usados em projetos reais — generics, mapped types e configuração de tsconfig.

## 📂 Conteúdo

- `types.ts` — interfaces, unions, generics
- `utils.ts` — funções tipadas do dia a dia
- `tsconfig.json` — configuração recomendada

## 🚀 Quick start

```bash
npm i -g typescript
tsc types.ts && node types.js
```

## 🧠 Tópicos

`types` `interfaces` `generics` `mapped types` `unions` `narrowing` `tsconfig`
